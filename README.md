# VoxCraft

**VoxCraft** is a work-in-progress 3D voxel-based game built using the **VoxCore Game Engine**. It is a simple demonstration of the engine's capabilities and currently serves as a minimal Minecraft-like clone.

> ⚠️ This project is a WIP (Work in Progress) and may contain incomplete features.

## Features

- 3D voxel world
- Basic terrain generation
- Simple block placement and destruction
- Minimalistic Minecraft-style gameplay
- Cross-platform potential (tested on Windows)

## Getting Started

Currently, there is no detailed build or installation guide. Instructions for building and running the game will be added in future updates.
